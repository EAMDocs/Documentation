# Core Pillars

NuVision consolidates technology governance into five interconnected pillars:

```
+-----------------------------------------------------------------+
|                       NuVision Platform                         |
+-----------------------------------------------------------------+
|  1. Enterprise Architecture (EAM)  |  2. App Portfolio (APM)    |
|  3. IT Asset Management (ITAM)     |  4. Risk & Obsolescence    |
|  5. Business Portfolio & Roadmap   |  6. Vendor Portfolio       |
+-----------------------------------------------------------------+
```

- **Enterprise Architecture**: Capability maps, system landscapes, and phased roadmaps.
- **App Portfolio Management**: Cataloging, lifecycle tracking, and TIME scoring.
- **IT Asset Management**: Hardware, software, virtual, and cloud resource tracking.
- **Risk & Obsolescence**: Proactive alerts on End-of-Life, End-of-Support, and critical CVEs.
- **Business Portfolio**: Strategic initiative alignment with real-time KPI dashboards.
