# First Login

Once activated, follow these steps to sign in for the first time:

1. Open your tenant URL in a supported web browser.
2. Enter your corporate email and newly created password.
3. Enter the 6-digit MFA verification code from your authenticator app.
4. On first login, the **Onboarding Wizard** will automatically launch to guide you through:
   - Timezone and locale preferences
   - Notification channel subscriptions
   - Module access overview
   - Dashboard personalization
