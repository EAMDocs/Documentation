# Getting Started

Welcome to the NuVision onboarding guide. This section walks you through prerequisites, account activation, first login, and understanding default user roles.

### Quick Start Checklist

- [ ] Obtain your tenant URL (e.g., `https://yourorg.nuvision.pemvish.com`)
- [ ] Check inbox for account activation invitation (valid for 72 hours)
- [ ] Set up Multi-Factor Authentication (MFA) via TOTP app
- [ ] Complete the interactive Onboarding Wizard on initial sign-in
