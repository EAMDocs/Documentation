# Account Activation

What is NuVision

1. NuVision is a No-code Low-code Platform
2. Click the **Activate Account** link (active for **72 hours** from receipt).
3. Create a secure password:
   - Minimum 12 characters
   - At least one uppercase letter
   - At least one number
   - At least one special symbol (`!@#$%^&*`)
4. Scan the QR code using any TOTP authenticator (Google Authenticator, Microsoft Authenticator, or 1Password).
5. Enter the 6-digit confirmation code and accept the Terms of Use.
