# Audit Logs

NuVision maintains immutable, tamper-evident audit trails for all system actions:

- **Logged Events**: User logins, record creations, updates, deletions, permission escalations, and API calls.
- **Retention**: 12 months by default, configurable up to 7 years for regulatory compliance.
- **SIEM Export**: Stream logs in real time to Splunk, Microsoft Sentinel, or Datadog via webhooks.
