# Report Builder

Build custom reports without writing SQL:

1. Navigate to **Reports → Custom Report Builder**.
2. Select the primary entity (e.g., Applications, Assets, Risks).
3. Choose columns, apply multi-condition filters (AND/OR), and group by dimensions.
4. Select visual format: Grid Table, Bar Chart, Line Graph, or Pivot Summary.
5. Save and schedule automated email delivery (PDF or CSV) on a daily, weekly, or monthly schedule.
