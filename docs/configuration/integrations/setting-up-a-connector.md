# Setting Up a Connector

Follow these steps to activate a connector:

1. Navigate to **Settings → Integrations → Connector Library**.
2. Select the target integration tile and click **Configure**.
3. Provide authentication credentials (API Key, OAuth 2.0 Client Credentials, or Service Account).
4. Define sync cadence (Real-time webhook, Hourly, or Daily scheduled sweep).
5. Map external fields to NuVision entities using the drag-and-drop field mapper.
6. Click **Test Connection** to verify, then click **Activate**.
