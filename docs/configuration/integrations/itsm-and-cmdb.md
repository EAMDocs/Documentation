# ITSM and CMDB Connectors

Synchronize operational configurations with industry-leading service desks:

- **ServiceNow**: Bi-directional sync for Configuration Items (CIs), application services, and incidents.
- **Jira Service Management**: Ingest Jira Assets and map issue tickets to NuVision architecture records.
- **BMC Helix**: Synchronize enterprise CMDB topologies and lifecycle statuses.
