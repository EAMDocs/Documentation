# Cloud Platform Connectors

Automate cloud resource discovery via read-only cloud APIs:

- **Amazon Web Services (AWS)**: Discover EC2, RDS, Lambda, S3, and ingest AWS Cost Explorer data.
- **Microsoft Azure**: Inventory VMs, App Services, SQL Databases, and Azure Resource Graph entries.
- **Google Cloud Platform (GCP)**: Enumerate Compute Engine, GKE clusters, and Cloud SQL instances.
