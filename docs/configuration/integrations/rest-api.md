# REST API

Every data entity in NuVision is accessible programmatically:

- **API Specification**: Fully documented OpenAPI 3.0 standard.
- **Base Endpoint**: `https://api.nuvision.pemvish.com/v1/`
- **Authentication**: Bearer Token with role-scoped permissions.
- **Standard Capabilities**: Full CRUD, pagination, filtering, sorting, and bulk ingest endpoints.
