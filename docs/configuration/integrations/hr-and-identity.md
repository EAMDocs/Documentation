# HR and Identity Connectors

Ensure accurate asset assignment and access governance:

- **Workday & BambooHR**: Sync organizational structures, employee rosters, and department hierarchies.
- **Okta & Azure AD (Entra ID)**: Automate user provisioning and deprovisioning via SCIM 2.0.
- **Active Directory / LDAP**: Sync on-premises distribution groups and directory metadata.
