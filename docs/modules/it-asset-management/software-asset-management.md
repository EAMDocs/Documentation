# Software Asset Management

The **Software Asset Management (SAM)** sub-module automates software license compliance and contract reconciliation:

- **Automated Detection**: Discovers installed binaries, software packages, and SaaS usage.
- **License Models**: Supports per-seat, concurrent, core-based, processor-based, and subscription licenses.
- **Audit Preparedness**: Generates one-click audit-ready compliance reports for vendors including Microsoft, Oracle, SAP, and Adobe.
- **Optimization**: Highlights unused and underutilized licenses to enable immediate cost reclamation.
