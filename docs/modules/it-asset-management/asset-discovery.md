# Asset Discovery

NuVision supports continuous automated discovery through multiple collection methods:

- **Endpoint Agent**: Lightweight agent for Windows, macOS, and Linux endpoints reporting hardware configuration and installed software.
- **Agentless Network Discovery**: Scheduled SNMP, WMI, and SSH sweeps across subnets.
- **Cloud Connectors**: Direct read-only API connectors for AWS, Azure, and GCP resources.
- **ITSM/CMDB Synchronization**: Bi-directional sync with ServiceNow, Jira Assets, and BMC Helix.
