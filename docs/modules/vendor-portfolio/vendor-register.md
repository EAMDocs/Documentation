# Vendor Register

Maintain a single profile for each technology partner:

- **Vendor Details**: Company name, account executives, escalation contacts, support tiers.
- **Strategic Tiering**: Tier 1 (Critical), Tier 2 (Preferred), Tier 3 (Commodity).
- **Compliance & Security**: SOC 2, ISO 27001, GDPR, and insurance certificates with expiration tracking.
- **Associated Assets**: Instant reverse lookup of all applications and hardware provided by the vendor.
