# Business Capability Mapping

Business capabilities represent what an organization does to deliver customer value. The capability map provides an executive heatmap of organizational strengths and gaps.

### Steps to Build a Capability Map

1. Navigate to **EAM → Capability Map**.
2. Click **+ Add Capability** to define Level-1 domains (e.g., Customer Service, Supply Chain, Finance).
3. Add child capabilities (Level-2 and Level-3) to create granular sub-functions.
4. Overlay visual heatmaps based on:
   - Strategic Importance (High, Medium, Low)
   - Operational Maturity (Ad-hoc, Defined, Managed, Optimized)
   - Annual IT Spend
5. Link applications and vendors to each capability to visualize tech debt concentration.
