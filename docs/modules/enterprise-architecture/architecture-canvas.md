# Architecture Canvas

The Architecture Canvas provides an intuitive drag-and-drop workspace for designing enterprise blueprints.

### Key Capabilities

- **Multi-Layer Modeling**: Switch seamlessly between Business, Application, Information, and Technology layers.
- **Relational Connectors**: Drag relationships between systems to define data flows, protocols, and interface dependencies.
- **Automatic Layout Engines**: Apply hierarchical, orthogonal, or force-directed graph layouts with one click.
- **Export & Embedding**: Export models as vector SVG, high-resolution PNG, or embed dynamic live frames in Confluence or SharePoint.
