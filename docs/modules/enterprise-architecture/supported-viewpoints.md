# Supported Viewpoints

NuVision supports standard enterprise architecture viewpoints aligned with TOGAF and ArchiMate frameworks:

- **Business Process View**: Connects business capabilities to operational workflows.
- **Application Cooperation View**: Maps integrations, message queues, and API dependencies between systems.
- **Technology Infrastructure View**: Shows how applications map to on-prem servers, VMs, and cloud services.
- **Information Flow View**: Traces data lineage and classification (e.g., PII, PCI-DSS) across platforms.
