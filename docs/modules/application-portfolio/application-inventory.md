# Application Inventory

Every application profile in NuVision captures comprehensive operational, technical, and commercial data:

### Core Record Fields

- **General**: Application Name, Description, Version, Category, Criticality (Mission Critical, Business Operational, Administrative).
- **Ownership**: Business Owner, Technical Owner, Responsible Team.
- **Hosting**: On-Premise, SaaS, IaaS (AWS/Azure/GCP), Hybrid.
- **Financials**: Annual subscription/license cost, hosting cost, internal support run rate.
- **Compliance**: Data classification, regulatory scope (GDPR, HIPAA, SOC 2).
