# Release Notes

NuVision operates on a continuous 4-week release cycle with zero-downtime rolling deployments.

- **Notifications**: Check the in-app Bell icon in the top navigation bar for "What's New" release highlights.
- **Release Archive**: Detailed technical release notes are published at `https://pemvish.com/releases`.
- **Sandbox Testing**: Major capability releases are deployed to client staging/sandbox tenants two weeks prior to production promotion.
