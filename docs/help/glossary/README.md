# Glossary

Reference of key acronyms and terms used throughout NuVision:

- **APM**: Application Portfolio Management — Strategy and process for managing business software assets.
- **CMDB**: Configuration Management Database — Central repository of IT components and relational dependencies.
- **EAM**: Enterprise Architecture Management — Discipline aligning business capabilities with technical systems.
- **EOL**: End of Life — Date when a vendor discontinues manufacturing or selling a product.
- **EOS**: End of Support — Date when a vendor ceases all patches, updates, and technical assistance.
- **Ghost Asset**: An asset recorded in inventory or financial books that is not physically or digitally present.
- **HAM**: Hardware Asset Management — Process of tracking physical devices from procurement through disposal.
- **ITAM**: IT Asset Management — End-to-end management of all hardware, software, and cloud assets.
- **SAM**: Software Asset Management — Management of software entitlements, deployments, and compliance.
- **TIME Model**: Tolerate, Invest, Migrate, Eliminate — Standard portfolio rationalization framework.
- **Zero-Code Pipeline**: PEMVISH's configuration-driven integration architecture requiring no custom scripts.
