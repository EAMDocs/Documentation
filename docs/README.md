# NuVision User Manual

Welcome to the **PEMVISH NuVision User Manual**. NuVision is a unified command centre combining Enterprise Architecture Management (EAM), Application Portfolio Management (APM), IT Asset Management (ITAM), Technology Risk & Obsolescence Management, and Business Portfolio Governance into a single, configuration-driven SaaS platform.

## About PEMVISH LLC

Founded in 2022 and headquartered in Princeton, New Jersey, **PEMVISH LLC** builds modern, configuration-driven enterprise technology governance solutions. Our flagship platform, **NuVision**, is a SOC 2 Type II compliant serverless SaaS platform that helps mid-to-large enterprises streamline operations, reduce software complexity, and maintain technology governance without requiring extensive custom code.
